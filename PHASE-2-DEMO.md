# SFA Phase 2 – manager demonstration

The Phase 2 flow is built inside **SFA Mobile Home** and uses the original visit as its context.

1. Start the day and open **My Route**.
2. Check in to **Nandi Daily Mart** (a new creative demo outlet, not the outlet from the recording).
3. Select **Take Order**. Add cases/pieces of **Sunrise Millet Bites** and submit. Salesforce calculates total quantity, net amount, GST and gross amount.
4. Select **Visit Actions** and demonstrate:
   - **Asset Survey** – asset name/code, status, given date and evidence URL.
   - **Competitor Activity** – competitor/company, MRP, RBP, scheme and evidence URL.
   - **Stock Check** – product, physical quantity and manufacturing date.
   - **Ticket** – auto-numbered ticket, subject, description and evidence URL.
   - **Product Return** – product, quantity, manufacturing date and return reason.
5. Select **Complete** to check out of the outlet.
6. Select **Apply Leave** to submit a dated leave request. The status begins as Pending and the employee's reporting manager becomes the approver.
7. Select **End My Day** to show login/logout locations and the end-day summary.

The related Salesforce tabs are grouped in the SFA Mobile app so the manager can verify each record after the mobile demonstration.
