Purpose: Validate an 18-character Salesforce ID and prefix it with I, P or R for invoice, product or return. Encode only the identifier, not prices or personal details.

export function barcodeValue(kind: "invoice" | "product" | "return", id: unknown): string | null

Inputs: kind: "invoice" | "product" | "return"; id: unknown

Read the execution in this order

  1. Branch on typeof id !== "string" || !/^[A-Za-z0-9]{18}$/.test(id).
  2. Return `${kind === "invoice" ? "I" : kind === "return" ? "R" : "P"}-${id}`.
