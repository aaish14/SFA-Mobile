verifyLoginCode · L79–87

Purpose: Require six digits and compare the supplied code against the current and previous windows using timing-safe equality.

export function verifyLoginCode(email: string, code: string)

Inputs: email: string; code: string

Read the execution in this order

  1. Branch on !/^\d{6}$/.test(code).
  2. const supplied = Buffer.from(code);
  3. const window = timeWindow();
  4. Return [window, window - 1].some((candidateWindow) => { const expected = Buffer.from(codeForWindow(email, candidateWindow)); return timingSafeEqual(supplied, expected); }).
