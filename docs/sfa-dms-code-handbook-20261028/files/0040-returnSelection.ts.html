selectWholeReturnOrder · L24–29

Purpose: Select each positive available balance, enforcing 1–50 lines and at most 100,000 whole units per line. It uses remaining received/ordered quantity, not the original quantity already reserved by other returns.

export function selectWholeReturnOrder(items: ReturnItem[]): Record<string, ReturnSelection>

Inputs: items: ReturnItem[]

Read the execution in this order

  1. const eligible = items.filter(item => item.available > 0);
  2. Branch on !eligible.length || eligible.length > 50 || eligible.some(item => !Number.isInteger(item.available) || item.available > 100000).
  3. Return Object.fromEntries(eligible.map(item => [item.id, { quantity: String(item.available), reason: "", notes: "" }])).

Branch and validation expressions

  • !eligible.length || eligible.length > 50 || eligible.some(item => !Number.isInteger(item.available) || item.available > 100000)
  • throws: new Error("Choose 1–50 returnable lines, with no more than 100,000 whole units per line.")
