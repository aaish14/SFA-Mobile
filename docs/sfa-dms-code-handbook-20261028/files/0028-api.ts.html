downloadInvoice · L8–19

Purpose: Fetch the issued invoice PDF using the distributor token and trigger the platform download/share flow.

export async function downloadInvoice(id: string, name: string, token: string)

Inputs: id: string; name: string; token: string

Read the execution in this order

  1. Branch on Platform.OS !== "web".
  2. const response = await fetch(`${base}/dms/invoices/${encodeURIComponent(id)}/pdf`, { headers: { Authorization: `Bearer ${token}` } });
  3. Branch on !response.ok.
  4. const blob = await response.blob();
  5. Branch on !blob.type.includes("pdf").
  6. const file = new File([blob], `${name.replace(/[^a-z0-9_-]/gi, "-")}.pdf`, { type: "application/pdf" });
  7. Branch on navigator.canShare?.({ files: [file] }).
  8. const url = URL.createObjectURL(blob), link = document.createElement("a");
  9. link.href = url;
  10. link.download = file.name;
  11. document.body.appendChild(link);
  12. link.click();
  13. link.remove();
  14. setTimeout(() => URL.revokeObjectURL(url), 10000);
