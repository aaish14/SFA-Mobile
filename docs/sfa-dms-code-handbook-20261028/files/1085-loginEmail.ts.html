sendDmsLoginCode · L60–73

Purpose: Choose the configured Gmail or Salesforce sender once per request. A Gmail failure does not silently send a second code through Salesforce.

export async function sendDmsLoginCode( email: string, code: string, salesforceSender: (email: string, code: string) => Promise<void>, ): Promise<void>

Inputs: email: string; code: string; salesforceSender: (email: string, code: string) => Promise<void>

Read the execution in this order

  1. const provider = process.env.DMS_MAIL_PROVIDER || "salesforce";
  2. Branch on provider === "gmail".
  3. Branch on provider !== "salesforce".
  4. Return salesforceSender(email, code).
